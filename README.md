# 🏎️ Brain Boost Racers

An arcade educational racing game where players answer grade-adapted math questions at track checkpoints to trigger nitro boosts, avoid spinouts, earn coins, manage savings in the Racer Math Bank, and customize their race car and driver avatar!

---

## 🎮 Game Overview

**Brain Boost Racers** combines high-speed 2D arcade racing powered by **Phaser 3** with interactive math challenges and financial literacy concepts. Players compete against dynamic AI racers on colorful tracks, pausing at math checkpoints to test their problem-solving skills. Quick and accurate answers deliver explosive nitro speed boosts to propel racers across the finish line!

---

## 🚀 Tech Stack

- **Frontend**: React 18, Vite, Vanilla JavaScript / JSX
- **Styling**: Tailwind CSS
- **Game Engine**: Phaser 3 (2D Canvas Renderer)
- **Icons & FX**: Lucide React, Motion (Framer Motion), Canvas Confetti
- **Audio**: Web Audio API Sound Synthesizer

---

## 🌟 Key Features

- 🏎️ **Arcade Phaser 3 Racing Engine**: Responsive controls, dynamic AI opponents, checkpoint timing, tire skid trails, and immersive turbo sound effects.
- 📐 **Grade-Adapted Math Checkpoints**: Dynamic math problem generation tailored for Grades K-8, featuring addition, subtraction, multiplication, division, fractions, geometry, and financial literacy questions.
- ⚡ **Nitro Boosts & Math Shields**: 
  - Correct answers reward a **4.5s Nitro Boost**.
  - Incorrect answers trigger a spinout penalty unless protected by a **Math Shield** power-up.
- 🏦 **Racer Math Bank & Compound Interest**: 
  - Deposit earned coins into a **Savings Vault**.
  - Earn automatic compound interest bonuses after every completed race based on grade level.
  - Interactive "Let's Learn Banking" storybook lesson and transaction history log.
- 🛠️ **Garage & Avatar Shop**: 
  - Fully customizable driver avatars with skin tones, hairstyles, and racing outfits.
  - Unlockable cars with stats for Top Speed, Acceleration, Handling, and Nitro.
  - Vehicle upgrades including custom paint colors, wheel rims, and engine tuning.
- 📱 **Mobile & Desktop Responsive Design**: High-contrast, vibrant UI built with React, Vite, and Tailwind CSS.

## 📄 Application Pages

| Page | Description |
|---|---|
| **Home / Main Menu** | Dashboard providing instant access to Race, Garage, Bank, Settings, and Grade selection. |
| **Grade Select** | Choose math difficulty level (Grades K–2, 3–5, 6–8) and target math topics. |
| **Car Select** | Select your racing car based on speed, acceleration, handling, and nitro ratings. |
| **Race Page** | The main Phaser 3 racing canvas with live speedometer, position counter, HUD, and checkpoint Math Modals. |
| **Shop & Garage** | Comprehensive catalog with grid layouts for purchasing cars, cosmetics, driver styling, and power-up shields. |
| **Racer Math Bank** | Financial literacy hub for managing deposits, withdrawals, savings goals, and compound interest rewards. |
| **Race Results** | Post-race breakdown showing placement, finish time, math accuracy stats, coins earned, and interest accrued. |
| **Instructions** | How-to-play guide detailing controls, checkpoint rules, Math Shields, and banking guidelines. |
| **Settings & Credits** | Audio/music toggles, data reset controls, and developer credits. |
